# Codveda Technologies Data Science Internship

A collection of data science and machine learning projects completed during my internship with **Codveda Technologies**.

This repository documents my progression through the internship, covering fundamental data science workflows, machine learning techniques, and advanced artificial intelligence applications.

---

## Overview

Throughout the internship, I worked on projects across the data science pipeline, including:

- Data Collection and Web Scraping
- Data Cleaning and Preprocessing
- Exploratory Data Analysis
- Predictive Modeling
- Classification
- Unsupervised Learning
- Natural Language Processing
- Neural Networks

The projects are organized according to the internship's three difficulty levels: **Basic, Intermediate, and Advanced**.

---

# Projects

## Level 1 — Basic

| Task | Project | Key Skills |
|------|---------|------------|
| Task 1 | Data Collection and Web Scraping | Python, Requests, BeautifulSoup, Pandas |
| Task 2 | Data Cleaning and Preprocessing | Pandas, Data Cleaning, Feature Preparation |
| Task 3 | Exploratory Data Analysis | Pandas, Matplotlib, Seaborn, Data Visualization |

---

## Level 2 — Intermediate

| Task | Project | Key Skills |
|------|---------|------------|
| Task 1 | Predictive Modeling (Regression) | Scikit-learn, Linear Regression, Decision Trees, Random Forest |
| Task 2 | Classification with Logistic Regression | Logistic Regression, Random Forest, SVM, Model Evaluation |
| Task 3 | Clustering (Unsupervised Learning) | K-Means, PCA, Silhouette Score, Customer Segmentation |

## Level 3 — Advanced
